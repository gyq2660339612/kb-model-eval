## 2. 任务类型 → 官方主指标(MTEB 口径)

| 任务类型 | 主指标 |
|---|---|
| Retrieval | **nDCG@10** |
| Reranking | **MAP**(eng 口径 MAP@1000) |
| STS / Summarization | Spearman 相关(基于余弦) |
| Classification | accuracy(C-MTEB 用 average precision) |
| Pair Classification | average precision(余弦) |
| Clustering | V-measure |
| Bitext Mining | F1 |
| Instruction Retrieval | Robustness@10 |

**不要错误使用平均分**:Mean(Task) 会掩盖检索表现;Embedding 选型优先看 **Retrieval** 列,Reranker/排序任务看 **Reranking** 列,再核对具体测试定义。

## 3. RAG 知识库场景的指标定义(本项目代码实现口径)

记号:对查询 q,`REL(q)` 为其全部相关文档集合,`rel(d) ∈ {0,1,2,3}` 为分级相关度,`rank(d)` 为名次(1 起)。所有指标先对单查询计分,再对查询集取**算术平均**。

| 指标 | 定义 | 说明 |
|---|---|---|
| **Recall@k** | `\|Top-k ∩ REL(q)\| / \|REL(q)\|` | 召回覆盖率,**召回环节最核心指标**;reranker 只处理 top-N 时,Recall@N 是其上限 |
| **Hit Rate@k** | 1 若 Top-k 含 ≥1 个相关文档,否则 0 | 等价 Success@k / **Coverage@k**;单相关文档时与 Recall@k 相同 |
| **Top-1 Accuracy** | = Hit Rate@1 | 报警码/型号/版本等**严格约束类**的核心指标(门槛建议 ≥0.95) |
| **Precision@k** | `\|Top-k ∩ REL(q)\| / k` | 前 k 条精确率;衡量 RAG 上下文噪声 |
| **MRR@k** | `1 / rank(首个相关文档)`;前 k 无相关记 0 | 第一个正确结果的位置,适合单答案问答 |
| **MAP@k** | `AP = (1/\|REL\|) Σ_{i:第i位相关} P@i`,取平均 | 多相关文档的整体排序质量 |
| **nDCG@k** | `DCG@k / IDCG@k`;`DCG@k = Σ (2^rel_i − 1)/log2(i+1)` | 支持分级相关度,**综合排序主指标**(trec_eval 增益形式) |
| **Pairwise Accuracy** | 等级不同的文档对中,高相关排在低相关前的比例 | 与 k 无关;衡量对**难负例**的区分能力,适合 reranker 对比 |
| **Δ指标** | `重排后 − 重排前`(ΔnDCG@10、ΔMRR@10) | reranker 净收益;只报重排后高分无法区分收益来源 |
| **Empty/Abstain** | 无答案查询被正确判"无可靠结果"的比例 | 本项目把全零标注查询**单独计数**(`num_unanswerable`),不进平均;拒答判定属系统层阈值策略 |

注意:

- nDCG 有两种增益形式:`rel/log2(i+1)`(原始)与 `(2^rel−1)/log2(i+1)`(trec_eval)。**本项目与 pytrec_eval/ranx 一致,采用后者**;与其他工具对分前务必核对。
- 比较不同模型必须固定 k、语料、候选集与 qrels;**不同模型原始 logit 的绝对值不可跨模型比较**(Qwen3-Reranker 默认输出 raw logit 差值),只比排序。
- 分级标注建议:3=直接回答/约束全满足,2=高度相关,1=部分相关,0=不相关或条件冲突(难负例显式标 0)。

## 4. 本项目评测维度(四大类)

1. **召回质量**(embedding):Recall@k、Hit Rate@k、nDCG@k、MRR@k、MAP@k、Pairwise Accuracy,k ∈ {1,3,5,10,20,50,100}(按语料规模截断);**按查询 category 分层出分**。
2. **精排质量**(reranker):固定候选集(推荐 top-100 冻结)重排,对比前后 nDCG@5/10、MRR@10、Precision@5、Top-1、Pairwise Accuracy 与 Δ 值;候选数量敏感性(top-20/50/100/200)。
3. **性能**:向量化吞吐(docs/s、tokens/s)、query 端到端 P50/P95/P99、rerank 单 query 延迟、峰值显存、CPU/RAM、启动时间、错误率(压测矩阵见 docs/06 §5 与 docs/08 §6 Phase 5)。
4. **成本**:向量维度(MRL 档位)→ 存储;量化档位 → 显存与精度折损;每百万查询成本。

**Embedding 控制变量**(实验时必须固定或单独对比):向量维度(MRL 至少测最大档与一个较小档)、归一化一致性、距离函数(cosine/IP/L2 与预处理匹配)、query 指令(默认/业务定制,document 侧不加)、输入长度与截断策略。
**Reranker 控制变量**:固定候选池与初始排序、固定 prompt/instruction、固定总 token 长度与截断、记录 batch/精度/padding/OOM。

## 5. 测试集(测试用例)格式速览

```
data/<dataset>/
├── corpus.jsonl    {"_id"|"id", "title", "text", "metadata"}
├── queries.jsonl   {"_id"|"id", "text", "labels", "relevant_doc_ids"(兜底)}
└── qrels.tsv       query-id <TAB> corpus-id <TAB> score(0-3 分级;亦支持 qrels.jsonl)
```

- 规模建议:smoke 30–50、pilot 200–300、正式验收 800–2,000、回归每次 +50–100。
- 项目自带 `data/sample/` 半导体示例(26 篇文档、11 条查询,覆盖 exact_match/numeric_constraint/unanswerable 等类别及显式难负例)。
- **构建与标注细则(pooling、双人复核、防泄漏、13 类分层)见 [docs/07](07-测试集构建与标注指南.md)。**

## 6. 验收标准(建议门槛,试点起点)

在自建领域测试集上,**准入/验收双门槛**(数值可按业务上调;硬门槛细则见 docs/08 §3.2):

| 维度 | 准入门槛(可上线灰度) | 验收目标(正式切换) |
|---|---|---|
| Recall@10(样本集)/ Recall@20(正式集) | ≥ 0.80 | ≥ 0.90 |
| Hit Rate@5 | ≥ 0.85 | ≥ 0.92 |
| nDCG@10(召回) | ≥ 0.60 | ≥ 0.75 |
| nDCG@10(重排后) | 较召回 +5% 以上 | 较召回 +10% 以上且统计稳定 |
| MRR@10(重排后) | ≥ 0.70 | ≥ 0.80 |
| 严格约束类(exact_match 等)Top-1 | ≥ 0.95(不达标不得仅凭总分上线) | 同左 |
| query 延迟 P95(召回) | ≤ 100 ms | ≤ 50 ms |
| rerank 延迟 P95(top-20) | ≤ 500 ms | ≤ 300 ms |
| 向量化吞吐 | ≥ 50 docs/s | ≥ 200 docs/s |

默认值存于 `configs/eval_config.json`(`acceptance_thresholds` + `category_gates`),报告自动判 PASS/FAIL;`composite_score` 给出 0–100 综合分(质量项,权重见 configs)。

## 7. 统计可信度与模型对比

- 相同 Query 集成对比较;同时报告**绝对变化**与**相对变化**。
- 差异较小时不得凭 1 次运行下结论:性能测试 ≥3 轮,指标脚本确定性可复跑。
- 逐 query 配对 bootstrap(本项目脚本):

```bash
python scripts/compare_runs.py results/runA/per_query_results.jsonl \
    results/runB/per_query_results.jsonl --metric ndcg@10
```

输出 Δ 均值、95% CI、胜负统计;CI 含 0 → 差异不显著,需扩大测试集。

| 工具 | 用途 | 用法要点 |
|---|---|---|
| `mteb` | MTEB/C-MTEB 全量复现 | `mteb.evaluate(model, tasks)`;CLI `mteb run -m <model> -t <task>`;以当前官方文档为准 |
