# 06 · 内网部署指南

> 目标:在**完全离线的内网 GPU 服务器**上部署 Qwen3-Embedding-8B + Qwen3-Reranker-8B,并提供 OpenAI 兼容 API 供知识库系统与本项目评测代码调用。调研时间 2026-10。

## 0. 总体流程

```
[联网机/边界机]                [内网]
下载模型权重 ──────────────► 拷贝权重到模型服务器
下载 Docker 镜像 / pip 包 ──► docker load / pip install --no-index
                              vLLM/TEI 启动服务 ──► 评测脚本调用 /v1/embeddings、/rerank
```

## 1. 模型权重下载(联网机)

### 1.1 ModelScope(国内首选)

```bash
pip install modelscope
modelscope download --model Qwen/Qwen3-Embedding-8B --local_dir ./models/Qwen3-Embedding-8B
modelscope download --model Qwen/Qwen3-Reranker-8B --local_dir ./models/Qwen3-Reranker-8B
# 小参数对照模型
modelscope download --model Qwen/Qwen3-Embedding-0.6B --local_dir ./models/Qwen3-Embedding-0.6B
modelscope download --model Qwen/Qwen3-Reranker-0.6B --local_dir ./models/Qwen3-Reranker-0.6B
modelscope download --model BAAI/bge-m3 --local_dir ./models/bge-m3
modelscope download --model BAAI/bge-reranker-v2-m3 --local_dir ./models/bge-reranker-v2-m3
```

也可直接使用本项目脚本:`python scripts/download_models.py --source modelscope --models all`

### 1.2 HuggingFace(含镜像)

```bash
pip install -U "huggingface_hub[cli]"
export HF_ENDPOINT=https://hf-mirror.com        # 社区镜像,直连可行时可省略
huggingface-cli download Qwen/Qwen3-Embedding-8B --local-dir ./models/Qwen3-Embedding-8B
# 也可:git lfs install && git clone https://huggingface.co/Qwen/Qwen3-Embedding-8B
```

设了 `HF_ENDPOINT` 后,transformers / vLLM 代码零改动自动走镜像。下载完成后通过合规渠道(移动介质/内网文件摆渡)拷入内网。

## 2. 运行时安装(内网离线)

**优先推荐 Docker 镜像搬运**:

```bash
# 联网机
docker pull vllm/vllm-openai:latest          # vLLM(官方 OpenAI 兼容服务)
docker save vllm/vllm-openai:latest -o vllm-openai.tar
# 内网
docker load -i vllm-openai.tar
```

备选 pip 离线包(要求 Python 3.10–3.13、Linux、CUDA 变体与目标机一致):

```bash
# 联网机(同 OS/Python/CUDA)
pip download vllm -d ./wheels
# 内网
pip install --no-index --find-links=./wheels vllm
```

环境要求:vLLM 完整功能仅支持 Linux;wheel 自带 CUDA 12.x 二进制,Blackwell(B200/GB200)需 CUDA ≥12.8;TEI 要求驱动兼容 CUDA 12.2+,且 **GPU 计算能力 ≥7.5**(V100 不可用)。

## 3. vLLM 部署(推荐生产方案)

### 3.1 Embedding 服务

```bash
vllm serve /models/Qwen3-Embedding-8B \
  --runner pooling \
  --dtype bfloat16 \
  --max-model-len 8192 \
  --gpu-memory-utilization 0.90 \
  --served-model-name qwen3-embedding-8b \
  --api-key sk-your-intranet-key \
  --host 0.0.0.0 --port 8000
```

或直接执行 `scripts/serve_vllm_embedding.sh`。要点:

- `--max-model-len 8192`:默认按 32K 分配,限制到 8192 显著省显存(知识库 chunk 一般不超过 8K);
- 多卡:`--tensor-parallel-size 2`;
- 量化:官方未发布 FP8/AWQ 版 Embedding 权重(只有官方 GGUF)。可用 `--quantization fp8` 做在线动态量化;**量化对检索精度的影响必须用本项目评测代码实测**;
- 内网若让 vLLM 直接拉 ModelScope:`VLLM_USE_MODELSCOPE=True`(需内网可达 ModelScope,否则用本地路径)。

调用(OpenAI 兼容):

```python
from openai import OpenAI
client = OpenAI(api_key="sk-your-intranet-key", base_url="http://127.0.0.1:8000/v1")
resp = client.embeddings.create(
    model="qwen3-embedding-8b",
    input=["Instruct: 检索能回答问题的知识库文档\nQuery: 什么是EUV光刻?",   # query 加指令
           "EUV光刻使用13.5nm波长的极紫外光源……"],                          # document 不加
    # dimensions=1024,   # MRL 截断(可选)
)
```

### 3.2 Reranker 服务(关键坑点)

Qwen3-Reranker 原始权重是 CausalLM(对 151,669 词表算 logits,低效且不支持 score API),**必须转换**:

方式 A — 启动时 hf_overrides 转换:

```bash
vllm serve /models/Qwen3-Reranker-8B --runner pooling \
  --hf_overrides '{"architectures": ["Qwen3ForSequenceClassification"],"classifier_from_token": ["no", "yes"],"is_original_qwen3_reranker": true}' \
  --chat-template examples/pooling/score/template/qwen3_reranker.jinja \
  --host 0.0.0.0 --port 8001
```

方式 B — 先离线转换再部署(更高效,推荐):

```bash
# 转换脚本在 vLLM 源码 examples/pooling/score/ 下,需随代码拷入内网
python convert_model_to_seq_cls.py --model_name /models/Qwen3-Reranker-8B \
  --classifier_from_tokens '["no", "yes"]' --method from_2_way_softmax \
  --path /models/Qwen3-Reranker-8B-seq-cls
vllm serve /models/Qwen3-Reranker-8B-seq-cls --runner pooling \
  --chat-template qwen3_reranker.jinja --host 0.0.0.0 --port 8001
```

注意:`qwen3_reranker.jinja` 模板文件位于 vLLM 源码仓库 `examples/pooling/score/template/`,内网部署需一并拷贝;模板内置默认 instruction,可在请求中通过 `instruction` 字段覆盖。

调用:

```python
import requests
# /rerank(Jina/Cohere 兼容)
requests.post("http://127.0.0.1:8001/rerank", json={
    "model": "/models/Qwen3-Reranker-8B-seq-cls",
    "query": "什么是EUV光刻?",
    "documents": ["EUV光刻使用13.5nm极紫外光……", "今天天气晴朗"],
    "top_n": 2})
# /score(成对打分)
requests.post("http://127.0.0.1:8001/score", json={
    "model": "...", "queries": ["..."], "documents": ["..."]})
```

## 4. 其他部署方案

### 4.1 HuggingFace TEI(轻量、Rust、动态批处理)

```bash
docker run --gpus all -p 8080:80 -v /models:/data \
  ghcr.io/huggingface/text-embeddings-inference:cuda-1.9 \
  --model-id /data/Qwen3-Embedding-8B --dtype float16
curl 127.0.0.1:8080/embed -X POST -d '{"inputs":"什么是EUV光刻?"}' -H 'Content-Type: application/json'
```

- 镜像按 GPU 架构选 tag:Turing `turing-1.9`、Ampere 8.0 `1.9`、Ampere 8.6 `86-1.9`、Ada `89-1.9`、Hopper `hopper-1.9`、Blackwell `100-1.9`;CPU 用 `cpu-1.9`;ROCm 用 `rocm-latest`。
- 官方支持 Qwen3-Embedding 全系(≥1.7.2);`/rerank` 端点面向传统 cross-encoder(bge-reranker 可用),**Qwen3-Reranker(yes/no 型)未在官方支持表中,需自行验证**。
- 默认 `--max-concurrent-requests 512`、`--max-batch-tokens 16384`;`--api-key` 开鉴权。

### 4.2 SGLang

```bash
python3 -m sglang.launch_server --model-path /models/Qwen3-Embedding-8B \
  --is-embedding --host 0.0.0.0 --port 30000
# MRL 截断:--json-model-override-args '{"matryoshka_dimensions": [128,256,512,1024]}'
```

注意:**Qwen3-Reranker 不能加 `--is-embedding`**,否则无法计算 yes/no logprob。

### 4.3 Xinference(最省事,适合对接 Dify/FastGPT/RAGFlow/MaxKB)

```bash
pip install xinference   # 或 docker pull xprobe/xinference
xinference-local -H 0.0.0.0        # 默认端口 9997,带 Web UI
xinference launch --model-name Qwen3-Embedding-8B --model-type embedding
xinference launch --model-name Qwen3-Reranker-8B --model-type rerank
```

离线要点:`XINFERENCE_MODEL_SRC=modelscope` 强制走 ModelScope;已下载权重用 `--model-path` 直接挂载;`HF_HUB_OFFLINE=1` 禁止联网探测。

### 4.4 Ollama(边缘/CPU 小规模验证)

```bash
ollama pull qwen3-embedding:8b      # GGUF;也有 0.6b/4b
curl http://localhost:11434/api/embed -d '{"model":"qwen3-embedding:8b","input":"..."}'
```

纯内网分发:下载官方 `Qwen/Qwen3-Embedding-*-GGUF` 后写 Modelfile `FROM ./xxx.gguf`,`ollama create` 导入。Reranker 官方库没有,可用社区 GGUF(如 `dengcao/Qwen3-Reranker-0.6B:F16`)。**吞吐低,不适合大并发批量建库**。

### 4.5 sentence-transformers(离线批处理/嵌入式)

```python
import os
os.environ["HF_HUB_OFFLINE"] = "1"; os.environ["TRANSFORMERS_OFFLINE"] = "1"
from sentence_transformers import SentenceTransformer, CrossEncoder
emb = SentenceTransformer("/models/Qwen3-Embedding-8B",
                          model_kwargs={"attn_implementation": "flash_attention_2"},
                          tokenizer_kwargs={"padding_side": "left"})
emb.encode(queries, prompt_name="query")     # query 带指令
emb.encode(documents)                        # document 不带
reranker = CrossEncoder("/models/Qwen3-Reranker-8B",
                        activation_fn=torch.nn.Sigmoid())   # 输出 0-1 分
reranker.predict([[q, d] for d in docs])
```

适合离线建库与调试;无连续批调度,高并发在线服务弱于 vLLM/TEI。

## 5. 性能参考(公开数据)

- vLLM 官方声明:pooling 模型支持"主要为便利性,不保证吞吐优于 sentence-transformers"。
- Snowflake 工程博客(2025-06):vLLM 原生 embedding HTTP 路径 90% 时间耗在 CPU(分词+序列化);TEI 在短序列上快于原生 vLLM 约 2.4 倍。优化(预分词/Arctic Inference)后 vLLM 可达 1.4M tokens/s/GPU。
- vllm-ascend 实测(Qwen3-Embedding-8B,昇腾 NPU,200 token 输入×1000 请求):31.11 req/s、15,929 tok/s、平均延迟 4423 ms。
- **vLLM vs sentence-transformers 同条件对比无权威公开数据——建议用本项目代码在内网实测**。
