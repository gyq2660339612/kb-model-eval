| 维度 | 每向量 | 100 万条 |

## 3. 单卡部署显存预算建议

| GPU | 可行组合 |
|---|---|
| 16 GB(如 RTX 4080/T4×2) | Embedding-4B + Reranker-4B(bf16,限 max-len 8192)或 Embedding-8B FP8 单跑 |
| 24 GB(如 RTX 4090/A10) | **Embedding-8B + Reranker-8B 同卡 bf16**(权重约 32.6 GB 超 24 GB——需 FP8 或分两卡);推荐 Embedding-8B(bf16)+ Reranker-4B |
| 48 GB(如 A6000/L40S) | Embedding-8B + Reranker-8B bf16 双模型同卡 |
| 无 GPU | 0.6B 系列 GGUF 走 Ollama/llama.cpp,或 TEI cpu 镜像;仅适合小规模验证 |

> Embedding 服务无自回归 decode,KV cache 占用小,显存大头是权重;用 `--max-model-len 8192` 限制默认 32K 的分配可显著省显存。

## 4. 协议与商用风险

| 模型 | 协议 | 内网商用 |
|---|---|---|
| Qwen3-Embedding / Reranker 全系 | Apache-2.0 | ✅ 无限制 |
| BGE-M3、bge-v1.5 全系、BGE-VL | MIT | ✅ 无限制 |
| bge-reranker-v2-m3、bge-code-v1 | Apache-2.0 | ✅ 无限制 |
| bge-multilingual-gemma2、reranker-v2-gemma | Gemma Terms | ⚠️ 需法务审阅 Google Gemma 条款 |
| Gemini / voyage / OpenAI 等 | 闭源 API | ❌ 内网离线不可用 |
